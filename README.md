# 📚 Semestre 2 - Técnico Laboral en Asistente en Desarrollo de Software

Bienvenido al repositorio del **Segundo Semestre** de mi formación como **Técnico Laboral en Asistente en Desarrollo de Software** en **CESDE**.

Aquí se almacenarán los proyectos, talleres, ejercicios y recursos desarrollados durante las diferentes asignaturas del semestre.

## 📖 Contenido

### 🎨 Frontend
Desarrollo de interfaces web utilizando tecnologías como HTML, CSS, JavaScript y frameworks relacionados.

### ⚙️ Backend
Desarrollo de la lógica del servidor, APIs, autenticación y demás componentes del lado del servidor.

### 🗄️ Bases de Datos
Modelado de datos, diseño de bases de datos, SQL, normalización y administración de información.

### 🎓 Cursos
Material complementario, ejercicios y actividades de cursos adicionales relacionados con el desarrollo de software.

### 🚀 Proyecto Integrador
Proyecto principal del semestre donde se aplicarán los conocimientos adquiridos en todas las asignaturas.
